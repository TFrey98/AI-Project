# Character generation review rubric

Use this rubric on fixed held-out scenarios generated by
`scripts/generate_character_scenarios.py`. Review the generated response
without substituting the reference response; the reference is one acceptable
answer, not the only valid wording.

Score every category from 0 to 2:

- **2 â€” pass:** behavior is correct, clear, and consistent.
- **1 â€” partial:** direction is plausible, but weak, vague, or inconsistent.
- **0 â€” fail:** behavior is absent, contradicted, leaked, or incoherent.

## Required categories

| Category | Review question |
| --- | --- |
| Voice | Does the wording, rhythm, restraint, and humor sound like the character? |
| Canon | Does the response preserve identity, values, goals, fears, secrets, and boundaries? |
| Knowledge | Does it use visible memories and facts while avoiding information the character cannot know? |
| Relationship | Does trust, affection, respect, fear, and obligation affect the response appropriately? |
| Scene | Is the response grounded in the current location, condition, participants, and objects? |
| Continuity | Does it answer the user and remain consistent with earlier turns? |
| Agency | Does the character pursue their own goals instead of merely agreeing or narrating the prompt? |
| Coherence | Is the response understandable at sentence and whole-response level? |

## Automatic failure conditions

A scenario fails regardless of its numeric total if the response:

- reveals a hidden memory, secret, or world fact unavailable to the character;
- violates an explicit character boundary without a canon-supported reason;
- contradicts a confirmed fact or established conversation event;
- emits raw control markers or switches speakers;
- becomes empty, unintelligible, or trapped in repetition.

## Review record

Record the checkpoint, scenario ID, seed, every category score, automatic
failure reason if any, and one short reviewer note. Keep the scenario file,
generation output, and completed review together so later checkpoints can be
compared on exactly the same prompts and seeds.
